# Channels

One folder per sales channel: API notes, account structure, listing and
settlement specifics, integration code or connectors.

- `amazon/` (UK first, then DE, FR, IT, ES)
- `shopify/` (D2C)
- `walmart/` (Walmart Online)
- `ebay/`

Retailer online platforms such as Tesco Online are where retailers now test
products before listing in store, so they are the bridge to physical retail.
