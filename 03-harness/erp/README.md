# ERP layer

We configure an existing ERP, we do not build one. Selection owner: Julien.
Candidates named so far: Microsoft Dynamics 365, NetSuite, or an open-source
ERP built for AI-native workflows. Criteria to score: cost per brand per
geography for a $500k to $1bn brand, CPG fit out of the box, API and agent
friendliness, multi-entity support, vendor AI roadmap.

Configuration specs by process domain:

- `order-to-cash/`
- `procure-to-pay/`
- `finance/`
- `gtm-channels/`: channel-specific sales configuration (Amazon, Shopify, Walmart Online, eBay, ...)
- `category-management/`: doubles as the insights and analytics function
